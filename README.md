# 💼 Job Tracker Application

A modern web-based **Job Tracker Application** designed to help users efficiently manage job applications while providing advanced insights and monitoring tools for SuperUsers.

---

## 🚀 Project Preview

### 👤 User Dashboard
![User Dashboard](https://i.imgur.com/kwJnVJL.png)

The main landing page for users. It provides a quick overview of job applications, statuses, and key activity metrics.

---

### 📊 Job Applications Overview
![Job Applications Overview](https://i.imgur.com/FEmtEJm.png)

A centralized view of all job applications across the platform, enabling better monitoring and management.

---

### ➕ Add Job Application
![Add Job Application](https://i.imgur.com/TcVIZfH.png)

A simple and intuitive form that allows users to add new job applications, including company details, role, and status.

---

## 🛠️ SuperUser Features

These features are designed specifically for administrative users (SuperUsers) to monitor system-wide activity and trends.

---

### 🧑‍💼 SuperUser Dashboard
![SuperUser Dashboard](https://i.imgur.com/QkzKNMi.png)

Provides a high-level overview of all user activity, application statistics, and system insights.

---

### 📜 Activity Log (SuperUser)
![Activity Log](https://i.imgur.com/QMN64m9.png)

Tracks all user actions within the system, offering full visibility into activities such as application creation, updates, and system interactions.

---

### 🌍 Global Notifications
![Global Notifications](https://i.imgur.com/BC29zTz.png)

Allows SuperUsers to broadcast important messages or updates to all users within the platform.

---

### 📄 All Applications
![All Applications](https://i.imgur.com/ZiZPeh9.png)

Displays a complete list of all job applications submitted by users. Users can easily browse, track, and manage their applications in one place.

---

### 📈 Job Trends (SuperUser)
![Job Trends](https://i.imgur.com/FoTHNUz.png)

Visual insights into job application trends, helping SuperUsers analyze patterns, growth, and user engagement over time.
